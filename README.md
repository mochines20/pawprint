# Pawprint

Pawprint is a browser-first progressive web app for photographing street cats, collecting sightings, and helping protect cats through privacy-aware community features.

## Current project status

This repository is at the documentation and planning stage. The initial product requirements are captured in the attached product documentation and translated into the first implementation sprint below.

## Documentation

- [Sprint 01: Documentation and Core Functions](docs/SPRINT-01-DOCUMENTATION-AND-FUNCTIONS.md)
- [Function Contracts](docs/FUNCTION-CONTRACTS.md)

The proposed MVP stack is Next.js/React, MapLibre GL JS with Supercluster, Supabase/Postgres with PostGIS and Storage, and a small AI validation service. These are implementation recommendations, not yet installed dependencies.
